A3VR Hybrid is an experimental public-alpha OpenXR bridge for 64-bit Arma 3.

PUBLIC ALPHA: 1.13.1-alpha.1

FEATURES
- 6DoF headset tracking through FreeTrack
- Right-controller motion aiming using Arma's native weapon
- Fire, ADS, reload, fire mode, grenade, weapon swap and interaction binds
- Left-stick movement, sprint and right-stick smooth turning/stance input
- Automatic startup from the official Arma 3 Launcher
- Sharp comfort-mono profile with a 4K internal Ultra preset
- Compatible with additional mods and DLC presets in the official Launcher

META TOUCH DEFAULTS
- Right trigger: fire
- Right grip: aim down sights
- Right A: reload
- Right B: throw grenade
- Right stick click: fire mode
- Left stick: move/strafe; click to sprint
- Right stick horizontal: smooth turn
- Right stick up/down: stand/crouch
- Left X: interact
- Left Y: switch primary/sidearm
- F8: recenter; F9: toggle motion aim; F10: force/release VR UI mode

TESTED WITH
Meta Quest over Air Link, S.O.G. Prairie Fire, CBA_A3, ACE, Zeus Enhanced,
Suppress, Align, Immerse and True Death. These are not required dependencies.
The Action Menu radial mod is not recommended in this alpha because its menu
bindings can conflict with VR input.

IMPORTANT LIMITATIONS
- This is not a native Arma 3 VR renderer or true per-eye stereo.
- Moderate black borders are intentional for clarity and reduced zoom.
- No independent physical hands, manual reload or physical inventory yet.
- Vehicles, Zeus/editor navigation, scopes and the VR UI cursor are experimental.
- Full stand/crouch/prone cycling is not reliable.
- Keyboard and mouse are strongly recommended for Arma's contextual shortcuts.
- Disable BattlEye. Do not use on protected multiplayer servers.
- Native binaries/PBO are not multiplayer-signed.
- Stop immediately if the image causes nausea, headache or eye strain.

Do not load another A3VR variant at the same time.
