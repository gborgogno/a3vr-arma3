A3VR Hybrid 1.0.0 is an experimental OpenXR bridge for 64-bit Arma 3.

Highlights:
- Experimental stereo VR gameplay and complete-frame menus/cinematics
- FreeTrack 6DoF headset tracking
- Controller-absolute, config-driven weapon proxy
- Native ammo, cadence, projectile, damage, sound, and reload synchronization
- Analog movement, smooth turn, stance controls, footsteps, recoil, and haptics
- Controller binds for map, inventory, laser/light, bipod, and weapon mode
- Physical mouse for start/configuration/Zeus/Eden/custom DLC interfaces
- One official Arma 3 Launcher workflow for every DLC/mod preset

Important:
- This is not a native engine VR renderer. Stop if stereo causes discomfort.
- Requires Windows x64, an active OpenXR runtime, FreeTrack, and PiP.
- Disable BattlEye and never join protected multiplayer servers with this mod.
- Do not load an older A3VR build at the same time.
- Modded weapons, custom campaign UI, vehicles, and non-Meta runtimes remain
  best-effort/experimental.
- The native binaries and PBO are not digitally signed. Verify the GitHub
  release SHA-256 before installation.

This is an unofficial community project and is not affiliated with Bohemia
Interactive.
